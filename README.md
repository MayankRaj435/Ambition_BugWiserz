## 🌟 What is this? (Non-technical friendly)

Ambition ML Platform helps you build Machine Learning models **without the headache**.

✅ Upload a dataset → ✅ train models automatically → ✅ understand results → ✅ deploy as an API  
All from a clean dashboard.

---

## ✨ Features

### 🤖 AutoML — Model Selection on Autopilot
No need to guess which model works best.  
Ambition trains multiple models and picks the top performer automatically.

### 🔍 Explainable AI (XAI)
Want to know *why* the model predicted something?  
We show **feature importance** with clear visuals using SHAP.

### 📦 Code Export
Download a ready-to-run Python script to reproduce training locally.  
Perfect for production & deployment workflows.

### 🚀 One-Click Deployment
Deploy your best model as a REST API endpoint instantly.  
Test predictions directly from the dashboard.

### 🎨 Modern UI with Animations
Smooth UI with Framer Motion + a sleek dark theme.  
Feels modern, clean and fast.

### 📊 Interactive Analytics
Real-time charts and evaluation metrics using Recharts for better insights.
